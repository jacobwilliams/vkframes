SegmentArtist

type, public, extends(TrajectoryArtist) :: SegmentArtist

Draws a line segment at every stride-th point of a trajectory (OpenFrames' SegmentArtist), from the point given by the start data sources to the one given by the end data sources: e.g. radius vectors (the origin to the positions), or from the positions to points stored as an optional (a target). Default (an addition to OpenFrames, which draws nothing until the sources are set): from the frame's origin to the trajectory's positions.

Relative ends (set_end_relative, not in OpenFrames): the end sources give an offset from the start, so a vector stored per point (a thrust, a velocity) is drawn from each position, at a length set by the end sources' scale (set_end_scale), which can be changed without touching the trajectory (only this artist's segments are written again). Where the vector is zero (no thrust) nothing is drawn.
