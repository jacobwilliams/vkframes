RibbonArtist

type, public, extends(ChainArtist) :: RibbonArtist

Draws a translucent surface swept between two points at each point of a trajectory (not in OpenFrames): from the point given by the start data sources to the one given by the end data sources, with a quad between each point's pair and the next's. Default: from the frame's origin to the positions, sweeping out an orbit's plane (a fan, as the radius vectors of a SegmentArtist would fill it); other sources give e.g. a curtain from the positions down to a ground track stored as an optional. Unlit, seen from both sides, depth tested but writing no depth (as the equatorial plane of a RadialPlane), drawn to double precision as the curves (its edge on a CurveArtist's line through the same points).

Trace mode draws the surface up to the current time: the quads passed (a draw range, no upload) and one from the last point passed to the point interpolated at the time. Point colors: a trajectory with colors colors the surface, each point's pair in its color, with the artist's opacity (its alpha times theirs); see set_point_colors. A trajectory going round several times covers the surface again each time, so it gets more opaque: trace one revolution, or lower the alpha.
