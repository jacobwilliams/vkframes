DataSource

type, public :: DataSource

Where one component (x, y or z) of a point is taken from, as OpenFrames' Trajectory::DataSource: src is a SOURCE_* constant; for SOURCE_POSOPT, element (1 to dof) of the position (opt = 0) or of optional opt; for SOURCE_ATTITUDE, element (1 to 4) of the quaternion. The value is multiplied by scale.
