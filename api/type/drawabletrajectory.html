DrawableTrajectory

type, public, extends(ReferenceFrame) :: DrawableTrajectory

A frame for drawing trajectories (OpenFrames' DrawableTrajectory): it holds artists, which draw in its coordinates.

procedure, public :: set_data_frame

  • private subroutine set_data_frame(self, frame)

    The frame of the scene its trajectories' data are in (see the module documentation): each point drawn where it is in this frame at the point's own time. Absent: this frame's own coordinates (the default). frame must be in the same tree (else the data are drawn as they are, with a warning) and stay alive while set. The frames' poses at the points' times are as the scene would place them then, follow modes included: a frame following with FOLLOW_LOOP (the default) wraps the points' times into its data's range too (at its data's last time, the first), so a frame following an ephemeris usually wants FOLLOW_LIMIT.

    Read more…
