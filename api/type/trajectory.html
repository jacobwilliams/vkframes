procedure, public :: compact

  • private subroutine compact(self)

    Free the storage not used: each array is reallocated to the points it holds (one copy, an array at a time), and arrays holding none are deallocated. For a trajectory that is complete: growing doubles the storage, so up to about half of it can be unused. The data and what is drawn of them don't change; pointers from times, positions, ... must be fetched again. Points can still be added (storage grows again).

    Arguments

    Type IntentOptional Attributes Name
    class(Trajectory), intent(inout) :: self
