The vkframes library, a modern Fortran library for visualizing spacecraft trajectories, rendering with VulkanSceneGraph. use vkframes gives the whole public API.

This umbrella module only re-exports the public types, procedures and constants of the vkf_* modules (math, trajectories and followers, the clock, reference frames and what extends them, windows and views, handles and the cursor's ray, HUD text and GUI panels, the sky, shapes, artists, line segments, shadows, terrain, file search, the cache, diagnostics); see each module for its documentation.
