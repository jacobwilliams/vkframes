Custom line segments, as OpenFrames' CustomLineSegments: a frame drawing line segments whose endpoints and colors (one per endpoint, blended along the segment) are set by the program (set_segments), or computed each frame by a callback (set_callback): e.g. lines of sight between spacecraft, or links between ground stations and satellites.

The endpoints are in the frame's own coordinates (the frame can move like any other); position_of(other) gives another frame's origin in them. The callback, an extension of the abstract LineSegmentsCallback (OpenFrames' CustomLineSegments::Callback), is called once per scene update with the simulation time, after the whole tree has been updated (ReferenceFrame%late_update), so the positions of other frames are those for that time whatever their place in the tree; it sets the segments with set_segments. Setting the same segments again uploads nothing.

The segments are drawn by a LineChain of separate segments (vkf_line_chain: thick lines in window units, square caps, dash patterns, points kept to double precision), with a color per point (vkf_line_create_colored). Without colors, the segments take the frame's color (set_color). (OpenFrames' custom line shader, setLineShader, isn't available: it would need GLSL compiled at run time.)

type, public, abstract ::  LineSegmentsCallback

Computes a CustomLineSegments' segments each frame: extend it with a compute procedure, which calls segments%set_segments (OpenFrames' CustomLineSegments::Callback). The program owns the callback object (it must stay alive while set).
