3D models: a model file (3ds, obj, glTF, ... through vsgXchange) in a frame, as OpenFrames' Model.

The model is placed in its frame by its own transform: translate(model_position) * rotate(model_attitude) * scale(model_scale) * translate(-model_pivot), so e.g. the pivot can be the model's center (model_bound) and the scale can size it.
