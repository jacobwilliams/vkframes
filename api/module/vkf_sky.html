The sky behind a scene (OpenFrames' SkySphere): a texture map and/or stars from a star catalog, at infinity (they turn with the view, never move with it), in the root frame's axes turned by the sky's attitude. A window shows a sky with WindowProxy%set_sky; one sky can be shown in several windows.

  • Texture: an equirectangular image of the sky (right ascension across, declination down; as a Sphere's texture map), e.g. OpenFrames' Images/StarMap.tif.

  • Stars: a star catalog in OpenFrames' text format (e.g. the HYG v3 catalog of OpenFrames, data/Stars_HYGv3.txt): a header line "ra[_limit] dec mag ci proper", then a star per line: right ascension (in hours, or 0 to limit if the header says "ra_limit", e.g. "ra_360.0"), declination (degrees), apparent magnitude, optional B-V color index and name. Stars in a magnitude range are drawn (at most a number of them, in catalog order), sized from their brightness between a minimum and a maximum size (window units), colored from their color index, and the smaller dimmed (OpenFrames' SkySphere::processStars and StarToPoint).

  • Star names: the names of the catalog's named stars drawn (those of them up to a magnitude), as labels beside them, at infinity as the stars (behind the scene); off by default (set_star_names). Shown with the stars (draw mode SKY_STARS).

  • Constellations: faint lines between their stars, from a constellation file (e.g. data/inp_Constellation.txt, Chris Dolan's outlines): "N name" starts a constellation, then a line per segment, "dec1 ra1 dec2 ra2" (degrees, hours), then an optional "# comment"; lines starting with "#" are comments. Off by default (set_constellations); at infinity, behind the stars, shown unless the draw mode is SKY_NONE.

Both are drawn when given (draw mode SKY_TEXTURE + SKY_STARS); the stars over the texture, by the brighter color.
