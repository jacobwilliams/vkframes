Fortran interfaces to the C++ VSG layer (src/vsg/vkf_layer.cpp, with src/vsg/vkf_rocky.cpp for Rocky maps and src/vsg/vkf_gui.cpp for GUI panels), and a few helpers that fill the layer's buffers in place.

Objects are opaque type(c_ptr) handles owned by the layer; release each one with its *_delete routine. Strings cross as (pointer, length). Functions returning integer(c_int) return 0 on success and -1 on failure unless documented otherwise; those returning a handle return null on failure.
