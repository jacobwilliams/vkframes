Text for vkframes: fonts (found by name on a search path, read once) and labels (text that always faces the screen).

A font is given as a file name (e.g. 'DejaVuSans.ttf', the default) or a path. A name is looked for in, in order: the directories of the VKFRAMES_FONT_PATH environment variable (separated by ':' or ';'), the fonts directory of the active conda/pixi environment (where pixi installs DejaVu), and the usual system font directories of macOS, Linux and Windows.
