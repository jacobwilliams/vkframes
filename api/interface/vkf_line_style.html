public function vkf_line_style(line) bind(C, name="vkf_line_style")

Arguments

Type IntentOptional Attributes Name
type(c_ptr), value :: line

line, marker or ribbon handle

Return Value type(c_ptr)

Description

A line's style buffer: 8 floats (r, g, b, a, width in window units, 1 for separate segments (pairs of points) or 0 for a strip, the dash pattern (16 bits; 65535 or 0: solid), window units per bit of it). Set the segment flag before drawing points. Null on failure.
