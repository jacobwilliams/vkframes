public function vkf_line_points(line, capacity) bind(C, name="vkf_line_points")

Arguments

Type IntentOptional Attributes Name
type(c_ptr), value :: line

line, marker or ribbon handle
integer(kind=c_int), intent(out) :: capacity

the buffer's capacity (points)

Return Value type(c_ptr)

Description

A line's point buffer, 8 floats per point (x, y, z and the distance along the strip from its start, high parts, then their low parts; see shaders/line.vert; markers ignore the distance), to fill in place; valid while the line handle exists. Null on failure.
