Arguments

Type IntentOptional Attributes Name

label handle (vkf_label_create)

1: at infinity; 0: at its position

Return Value integer(kind=c_int)

Description

Draw a label at infinity (on /= 0: its position a direction, in its parent's axes; at the far plane, behind the scene, as the sky's stars) or at its position (0). Returns 0, or -1 if not a label.
