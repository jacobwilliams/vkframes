public function vkf_ribbon_create(capacity, colored) bind(C, name="vkf_ribbon_create")

Arguments

Type IntentOptional Attributes Name
integer(kind=c_int), value :: capacity

the most points (even)
integer(kind=c_int), value :: colored

not 0: a color per point

Return Value type(c_ptr)

Description

A ribbon of up to capacity points (even): a translucent surface through pairs of points, a quad between each pair and the next; a color per point (vkf_line_colors) if colored is not 0. The buffers are a line's. A node handle, or null on failure.
