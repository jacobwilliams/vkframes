Description

A triangle mesh (a node handle), filled from Fortran (vkf_mesh_array, before the first frame); null on failure. A translucent mesh's bounding sphere (its coordinates), for depth sorting and culling. Returns 0, or -1 if it isn't a translucent mesh (vkf_mesh_create's flag 8).
