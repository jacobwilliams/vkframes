public function vkf_line_create(capacity) bind(C, name="vkf_line_create")

Arguments

Type IntentOptional Attributes Name
integer(kind=c_int), value :: capacity

the most points

Return Value type(c_ptr)

Description

A line strip holding up to capacity points (initially none): a node handle, or null on failure. Fortran fills its point and style buffers in place (vkf_line_points, vkf_line_style), then calls vkf_line_points_changed / vkf_line_style_changed. It can be shown in any number of windows.
