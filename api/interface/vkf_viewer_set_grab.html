Arguments

viewer handle (vkf_viewer_create)

1: armed; 0: not

Return Value integer(kind=c_int)

Description

Whether a left button press takes the mouse from the trackball (armed 1: a handle is under the cursor), until the button is released: those events are given with key 1 (vkf_viewer_events). Returns 0, or -1 on failure.
