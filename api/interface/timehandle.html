private function new_time_handle(name, path, time, t_min, t_max, color) result(h)

A time handle (see the module documentation) on path (which must stay alive while used), at time time (default 0) within t_min to t_max (default: the time), in color ([r, g, b] or [r, g, b, a]). Its axes and labels are hidden (its name label can be shown: e.g. the time).
