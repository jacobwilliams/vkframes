public function vkf_marker_create(capacity, image, colored) bind(C, name="vkf_marker_create")

Arguments

Type IntentOptional Attributes Name
integer(kind=c_int), value :: capacity

the most points
type(c_ptr), value :: image

image handle (vkf_image_read) for the image shape, or null
integer(kind=c_int), value :: colored

1: a color per marker, 0: the style's only

Return Value type(c_ptr)

Description

Markers at up to capacity points (initially none): a screen-space quad per point, of the shape and size in the style buffer (shaders/marker.vert); a node handle, or null on failure. The point and style buffers are those of a line (vkf_line_points, vkf_line_style, vkf_line_points_changed, vkf_line_set_range, vkf_line_style_changed); with colored (1), a color per marker (vkf_line_colors), times the style's.
