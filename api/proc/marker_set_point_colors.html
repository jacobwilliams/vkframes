marker_set_point_colors

private subroutine marker_set_point_colors(self, enabled)

How intermediate markers are spaced: INTERMEDIATE_TIME, _DISTANCE or _DATA. Point colors (default off): with the trajectory's colors (Trajectory% add_color, or add's color), each marker is drawn in the color at its point (intermediate markers between points: blended between theirs, by time), points without a color yet in the marker's own color (set_marker_color). Off, or without colors: the markers' own colors.

    subroutine marker_set_point_colors(self, enabled)
        class(MarkerArtist), intent(inout) :: self
        logical, intent(in) :: enabled
        if (enabled .eqv. self%point_colors_) return
        self%point_colors_ = enabled
        call rebuild_markers(self)
