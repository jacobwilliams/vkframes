local_matrix_at

private recursive function local_matrix_at(self, t) result(m)

The transform from this frame to its parent at simulation time t: its fixed position and attitude, with what it follows at time t (the followed trajectories' state then, in the parent's coordinates). The same as local_matrix after update at time t, for any t, without changing anything.

    recursive function local_matrix_at(self, t) result(m)
        class(ReferenceFrame), intent(in) :: self
        real(wp), intent(in) :: t                           !! simulation time
        real(wp) :: m(4,4)
        real(wp) :: pos(3), att(4)
        pos = self%position_
        att = self%attitude_
        if (self%following) call followed_pose(self, t, pos, att)
        m = frame_matrix(pos, att)
    end function local_matrix_at
